В __app.py__ К основному приложению монтируются служебный рут и сабприложения и с их рутами

Остальные директории для описания рутов и соответственных к ним моделей тел реквестов и респонсов

Рут включает в себя минимальную логику(описание самого рута, указание моделей реквест/респонснов, dependecies и т.д.)
и вызов сервиса где будет исполняться основная логика

Есть два типа рутов:

1. base - Служебные руты/модели
2. public - Публичные руты, предназначенные для запросов с клиентской части(фронт, внешние системы и т.д.)

Шаблонная форма директорий следующая:

```
├── router_folder   
│   └── v1      # условная версия приложения/роутов   
│       ├── app.py  # модуль где, инициализациируется сабприложение(у base отсутствует, так как это основной рут)   
│       ├── request  # директория для моделей реквестов  
│       ├── response  # директория для моделей респонсов  
│       └── router.py  # модуль где, объявляются руты(в private/provider и public присутствует примеры)
```
