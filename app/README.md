 __server.py__ Инициализация основного приложения, а также прикручивание middlewares  
  __configure_application.py__ Конфигурация приложения на lifespan

Остальные директории включает в себя модули сервисов и неразделимую от них логику

Сервис включает в себя основное логику исполнения запроса, отсюда может происходить вызов других сервисов, 
репозиториев, вспомогательных модулей из core

Также как и с рутами разделяются на два вида и соотвественно обслуживают соответствующие руты:

1. base
2. public

Шаблонная форма директорий следующая:

```
├── services_folder   
│   └── services      # Директория с сервисами    
```
