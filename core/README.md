Различная директории/модули связанный с core 

1. cache - Инициализация редиса и Enum баз
2. db - Иницилиазция постгреса, модели таблиц, миксины для таблицы
3. exceptions - специальные классы Exception, enum ошибок статус кодов:
   1. service
4. fastapi - логика связанная с библиотекой FastApi
   1. decorators - декоратары для рутов
   2. exceptions - дефолтные классы Exceptionov'ов
   3. middlewares - связуещее программное обеспечение
   4. schemas - схемы для dependencies
5. utils - дополнительные util модули которые, не выделяются в отдельную директорию
6. config.py - Конфиги приложения
